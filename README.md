# Collections of Python Projects 🐍

> **⚠️ LEGACY REPOSITORY:** This repository contains a collection of older Python projects completed in the past. It serves as an archive of my earlier work, learning progress, and scripting experiments. It is no longer actively maintained or updated.

## 📖 About
This repository holds a variety of beginner to intermediate Python projects, ranging from classic arcade games and desktop GUIs to web scraping scripts and basic web applications using Flask. 

## 📂 Project List
Here is a list of the projects included in this collection:

* **cookie-clicker:** An automated bot/script to play the popular Cookie Clicker game.
* **empire-scraping-movie:** A web scraping tool to extract top movie lists from Empire magazine.
* **iss-overhead-notifier-via-email:** A script that tracks the International Space Station (ISS) and sends an email notification when it is overhead.
* **number-guess-using-flask:** A simple web-based number guessing game built with the Flask framework.
* **pomodoro-timer:** A desktop GUI application for the Pomodoro productivity technique.
* **pong-game:** A recreation of the classic arcade game Pong.
* **snake-game:** A fully functional clone of the classic Snake game.
* **spotify-scraping-playlist:** A script that scrapes billboard data and automatically creates a Spotify playlist.
* **turtle-crossing-game:** A Frogger-style crossing game built using Python's Turtle module.
* **turtle-race-game:** A simple betting game where Turtle graphics race across the screen.
* **us-state-game:** An interactive geography game to guess all 50 US states.

## 🚀 How to Run
Since these are standalone projects, each folder contains its own self-contained code. 

1. Clone the repository:
   ```bash
   git clone [https://github.com/ziqkimi308/collections-of-python-projects.git](https://github.com/ziqkimi308/collections-of-python-projects.git)
   ```

2. Navigate into the specific project folder you want to test.
3. Run the main python file (usually `main.py`):
```bash
python main.py

```
